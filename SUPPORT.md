# Getting help

Taskrivet is an early desktop alpha maintained in the open. Support is best effort;
there is no response-time guarantee.

| Need | Where to go |
| --- | --- |
| Installation, usage, or a design question | [Q&A and discussions](https://github.com/hamanakam1/taskrivet/discussions) |
| A reproducible bug | [Bug report form](https://github.com/hamanakam1/taskrivet/issues/new?template=bug_report.yml) |
| A scoped improvement | [Feature request form](https://github.com/hamanakam1/taskrivet/issues/new?template=feature_request.yml) |
| Roadmap and active priorities | [Roadmap](docs/roadmap.md) and [milestones](https://github.com/hamanakam1/taskrivet/milestones) |
| Downloads and version-specific limits | [Releases](https://github.com/hamanakam1/taskrivet/releases) |
| A security vulnerability | [Private vulnerability report](https://github.com/hamanakam1/taskrivet/security/advisories/new) |

Search existing issues before creating another. Include the Taskrivet version or
commit, operating system, installation method, exact command, expected result,
actual result, and the smallest synthetic reproduction you can share.

Review logs and screenshots before posting. Remove credentials, private ticket
text, repository paths, account identifiers, terminal history, and customer data.
Do not upload your ledger, private config, full transcripts, or diagnostic archives.
A short redacted excerpt is usually enough to begin.

For a stuck agent, distinguish the terminal process from its ledger status. Closing
a desktop window does not stop the terminal. Follow the [desktop lifecycle guide](docs/desktop.md)
and [ticket loop guide](docs/ticket-loop.md); do not delete the ledger to retry work.
